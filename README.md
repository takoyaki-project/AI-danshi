## ✨ このゲームについて

ノーコード開発から生まれた、短編の恋愛シミュレーション風Webゲームです。

- オープニング演出
- 会話シーン
- 選択肢
- 好感度
- エンディング
- クレジット

---

## 🎮 できること

| 機能 | 内容 |
|---|---|
| オープニング演出 | タイトル・プロローグ・名前演出 |
| 選択肢 | 選んだ答えで好感度が変化 |
| エンディング | チャッピールートの短いエンディング |
| スマホ対応 | スマホでも遊べる画面サイズ |
